# 개발노트 — 회계기준서 목차 기반 '공시' 섹션 최상위 고정

## 2026-06-18 작업 내역

### 작업 내용
회계기준서(standards) 검색에서, 문서가 결과에 뜨면 **질의와 무관하게 그 문서 목차(TOC)의 '공시' 섹션 페이지를 1순위로 자동 미리보기**하도록 추가(Owner 결정: "항상 공시 섹션 고정"). 예: 제1016호(유형자산) → 목차 `공시 73~79` → page 29를 최상위.

### 변경 파일 (`src/app.py`)
- **`_parse_toc_disclosure(pages)`**(신규): 목차 페이지('목 차'/'문단번호' 포함)에서 제목 열·범위 열을 **순서대로 수집해 동일 인덱스로 페어링**(K-IFRS 목차는 제목 전체→'문단번호'→범위 전체 순으로 추출됨). '공시' 대응 범위 → `{para_start,para_end}`. 헤더('목 차'·'문단번호') 제외. 개수 불일치/공시 부재 → None.
- **`_resolve_section_page(pages, para_start)`**(신규): 본문에서 섹션 헤딩 라인 `=="공시"` 페이지 우선, 없으면 문단 앵커(para_start) 페이지. `base<=60` 인덱싱 가드와 무관한 독립 스캔(공시 문단>60 대응).
- **`_compute_standard_disclosure(pages)`**(신규): 위 둘 결합 → `{page_start[,para_start,para_end]}` 또는 None.
- **`build_standard_index`**: PDF 1회 오픈으로 `pages` 구성 → 문단 분할 + disclosure 계산. 인덱스 JSON 최상위에 `disclosure` 저장(구조화 인덱스만, 해석 성공 시).
- **`standards_search`**: 정렬 후 **최상위 결과 문서**의 `disclosure.page_start`로 **합성 '공시' source를 1순위 prepend**(doc_class=공시, section="📌 공시(목차 §..~..)", match_page=공시페이지, 중복 제거). disclosure 없으면 현행 유지.

### 데이터
- 기존 인덱스 24개에 `disclosure` 주입(재임베딩 없이 PDF 스캔→index_body.json 패치). 5개(현금흐름표·금융상품표시·중간재무보고·연결재무제표·타기업지분공시)는 '공시' 섹션 부재로 graceful skip(핀 없음).
