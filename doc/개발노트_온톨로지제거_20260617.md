# 개발노트 — 회계 개념 온톨로지·Graph-RAG 기능 제거

## 2026-06-17 작업 내역

### 작업 내용
RAG 탭의 "회계 개념 온톨로지 · Graph-RAG" 서브탭을 전면 제거(v0.6.0 → 0.7.0). 사전 조사 결과 이 기능은 **실데이터·검색과 무관한 프론트엔드 데모**였다.
- 백엔드 모듈 0, API 엔드포인트 0, 테스트 0, 외부 라이브러리 0.
- 개념 16·엣지 17·연결 주석이 모두 `index.html`에 **하드코딩된 더미**(4사 실인덱스 미연동).
- 피드백 큐(👍/👎·관계제안)는 영속화 미구현(PoC 설계 단계).
- 일반 검색(`/api/notes/rag`·`/api/compare`)은 온톨로지를 전혀 참조하지 않아 제거해도 무손상. 유일한 연결은 개념→자연어질의창 텍스트 전달(`kgxToRag`) 단방향 브리지뿐.

### 변경 파일
- **`src/static/index.html`** (약 496줄 삭제):
  - CSS: `.rag-subtabs`/`.rag-subtab`(서브탭), 미사용 `.kg-erd-*`/`.kg-card`/`.kg-rel-table`(구 온톨로지 도식 dead CSS), `#kgx-explorer .kgx-*`(그래프 explorer) 전부.
  - HTML: 온톨로지 서브탭 버튼 + `#rag-sub-onto`(그래프 SVG·주석카드·피드백큐) 블록. RAG 탭은 자연어 질의 단일 화면으로 복원.
  - JS: 온톨로지 엔진 IIFE(force-layout·doSearch·renderNotes·피드백 핸들러·`window.kgx*`) 전체, `showRagSub` 서브탭 전환 함수.
- **삭제 문서**: `doc/재사용패턴_개념온톨로지_GraphRAG_20260606.md`, `doc/개발노트_온톨로지검색통합_20260608.md`.
- **`VERSION`** 0.6.0 → 0.7.0.
