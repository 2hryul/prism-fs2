# 개발노트 — 재무제표 비교: 연간확정(FY) + 다년 시계열 보강

## 2026-06-17 작업 내역

### 작업 내용
"재무제표 비교 결정론" 탭이 4대 금융지주의 **모든 자료**를 보여주도록, 연간 확정(FY) 재무수치와 다년 시계열을 보강. v0.4.0(c6f4c87)에서 제거했던 FY(reprt_code 11011)를 **재무데이터(fnlttSinglAcntAll) 경로에 한해** 재도입.

핵심 판단(ideation): FS 비교의 *숫자*는 `fnlttSinglAcntAll`에서 나오며 v0.4.0에서 보존됨 → "모든 자료"의 실제 결손은 (1) 연간 확정치, (2) 다년 시계열이고, 이는 **XBRL·사업보고서(report.pdf) 없이** fnlttSinglAcntAll을 11011로 호출하면 채워짐. 사용자 확정: XBRL·report 재도입 없음(FS 숫자 보강만), FY 셀은 **FS-only**(PDF/주석/XBRL 미수집).

### 변경 파일
- **`src/collect_dart.py`**: `REPRT_TO_PERIOD_SUFFIX`/`REPRT_TO_PERIOD_MARK`에 `11011→FY/12` 추가, `list_date_window` 11011 익년 윈도(`{year+1}0101~0630`), `pick_target_report` nm_key `11011→"사업보고서"`. `collect_company`에 `is_fy` 분기 — FY는 fnlttSinglAcntAll만 수집하고 document.xml(source/)·attach_docs(검토보고서) 스킵. `build_request_plan`·`run_dry_run` 출력도 FY=FS-only 반영. argparse help/epilog 갱신.
- **`src/app.py`**: `PERIOD_PATTERN` `^\d{4}(Q[1-3]|FY)$`, `_PERIOD_ORDER`/`_SUFFIX_TO_REPRT`에 FY/11011 추가, `/api/fs/timeseries`에 `period_kind`(quarter/annual) 쿼리 추가.
- **`src/fs_compare.py`**: `cmp_col` FY 손익/CF는 전기 연간(frmtrm) 비교(분기 누적 frmtrm_q 아님), `_period_key` 추가로 `list_periods` 시간순 정렬(2025Q3<2025FY<2026Q1), `timeseries` `period_kind` 필터(분기/연간 미혼합), 반환에 `period_kind`.
- **`src/static/index.html`**: `PERIOD_TYPES`/`_PORDER`에 FY 추가, `periodLabel` FY="YYYY 연간확정(FY)", `renderFsControls`가 `LIBRARY.available_periods` 기반 기간 드롭다운(delta 뷰에도 기간 선택 추가) + 시계열 추이종류(분기/연간) 셀렉트, `fsViewTs`가 `period_kind` 전달, fs 헤더에 FY/Q 구분·FY 비교규칙 안내.
- **테스트**: `tests/test_fs_compare.py`에 cmp_col FY/정렬/period_kind/delta base 4건, `tests/test_collect_fy.py` 신규(period/window/mark/pick_target_report·FS-only 분기·app 매핑 9건). `tests/e2e/test_smoke.py`의 v0.4.0 잔존 깨짐 수정(fs-view 8→7, PDF 테스트 report→review·review_indexed).
- **데이터**: 2023FY/2024FY/2025FY × 4사 라이브 수집(CFS+OFS, source=0=FS-only, review 미수집). rescan으로 catalog 28셀 재구성.
- **`VERSION`** 0.4.0→0.5.0.

### 결정 사항
- **FY FS-only**: 사업보고서 본문은 감사보고서라 검토보고서(review) 경로와 다르고, 사용자가 숫자만 요구 → document.xml·attach_docs 스킵. catalog는 기존 "재무데이터만 수집"(bca48c3) 경로로 `fs_collected=true/review_collected=false` 등록.
- **FY 비교컬럼**: 연간 셀의 손익/CF는 frmtrm_q(분기 누적)가 의미 없어 전기 연간(frmtrm) 비교로 분기. BS는 분기·FY 동일 frmtrm(전기말).
- **시계열 분기/연간 분리**: 분기(누적)와 연간(12개월)을 한 줄 인접 Δ로 섞으면 의미 붕괴 → `period_kind` 필터로 동일 종류끼리만. 기본 quarter로 기존 동작 보존.
- **fs_compare 정렬키 복제**: app 역의존 금지 위해 `_period_key`를 fs_compare에 9줄 복제(값은 app `_PERIOD_ORDER`와 일관).
