## 2026-06-12 작업 내역 (2차) — 번들 슬림화 6.83GB → 2.55GB (-63%)

- **동기**: 6.83GB 의 65%(4.43GB)가 **GPU(CUDA)용 torch** — GPU 없는 데모 PC 에선
  죽은 무게. storage 의 xbrl/source(836MB)는 검색·뷰어 미사용.
- **방법**:
  1. **CPU torch 빌드 전용 venv**(`.venv-build`) — `torch==2.6.0` CPU 휠(1.14GB) +
     큐레이션된 런타임 deps. 개발환경 GPU torch 는 보존(인덱싱 속도 유지).
     camelot/cv2/av(미사용·번들 비대 주범) 의도적 미설치.
  2. `build.ps1`: 빌드 venv 의 PyInstaller 사용(gate pytest 는 시스템 python 유지),
     storage 복사 시 `robocopy /XD xbrl source`(836MB 제외) + 종료코드 누수 수정.
  3. `prism_fs.spec`: cv2/av/camelot/pypdf 등 excludes.
- **결과**: torch 4,429→1,102MB, storage 1,389→552MB, cv2/av 제거 → **2.55GB**.
- **빌드 전 `import app` 스모크가 잡은 누락**: `python-multipart`(업로드/import Form).
- **frozen exe 스모크가 드러낸 잠재 버그 2건(데모 PC=한글 윈도우에도 영향 — 실수정)**:
  1. **transformers 지연로딩 + PyInstaller**: `_LazyModule` 이 `__file__`(.pyc)로 소스를
     재탐색 → WinError 3 → **모델 로드 실패·bigram(512) 폴백**(검색 깨짐). 수정:
     spec `module_collection_mode={"transformers":"py","sentence_transformers":"py"}`.
  2. **cp949 콘솔 UnicodeEncodeError**: 기동 로그의 em-dash(—)를 한글 윈도우 콘솔이
