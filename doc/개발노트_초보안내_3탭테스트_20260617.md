### 식별한 초보 약점 → 보강
1. 전체 사용 흐름 안내 없음 → **라이브러리 상단 3단계 퀵스타트 배너**(①선택 →②비교조회/자연어질의 →③원문확인). 닫기 시 localStorage로 재노출 안 함.
2. 비교조회 vs 자연어 질의 차이 불명 → 두 탭에 **용도 한 줄 안내(tab-hint)** 상호 교차 안내(키워드 표 비교 ↔ 문장 질문 AI 답).
3. 매트릭스 숫자 의미 불명(사용자 문의) → 라이브러리 설명문에 "**숫자 = 인덱싱된 주석 개수**" 및 기간 머리글 클릭=일괄삭제 명시.
4. 자연어 질의 인트로를 "문장으로 질문하면 AI가 근거 주석으로 답" 중심으로 재작성, Ollama 미가동 시 동작 명시.

### 변경 파일 (`src/static/index.html`만)
- CSS: `.quickstart`(퀵스타트 배너)·`.tab-hint`(탭 용도 안내) 추가.
- 라이브러리: `#quickstart` 배너 + `dismissQuickstart()` + 로드 시 노출 로직(localStorage). 매트릭스 설명문 보강.
- 비교조회: 상단 `.tab-hint` 추가.
- 자연어 질의: 인트로 문구 재작성 + 비교조회 교차 안내.
