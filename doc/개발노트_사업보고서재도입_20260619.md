# 개발노트 — 사업보고서(report) 재도입

## 2026-06-19 08:40 작업 내역
- 작업 내용:
  - v0.4.0(`c6f4c87`)에서 제거했던 사업보고서를 **현 prism-fs 라이브러리 화면에 재도입**. 단순 revert가 아니라 현행 아키텍처(본문 전체 인덱싱·문장청크 schema4·cell_keys·S1)에 `report`를 **3번째 doc_type**으로 일관 이식.
  - Ideation/스펙 선행: `ideation/ideation_사업보고서재도입_20260619_0821.md`, `spec_사업보고서재도입_20260619_0821.md`(EARS).
- 변경 파일:
  - **백엔드** `src/app.py`:
    - `VALID_DOC_TYPES`에 `report` 추가, `validate_doc_type` 메시지, `pdf_path`(report.pdf)·`index_path`(index_report.json)·`_STANDARD_PDF_NAMES`·`_filename_matches_doc_type`(사업/분기/반기보고서 & 검토·감사 미포함)·`detect_doc_type_from_text` report 분기.
    - `_strip_doc_fields` report 분기 — **`report_nm`(DART 메타) 보존**(접두 충돌 회피).
    - 업로드 핸들러·인덱싱 카탈로그 갱신·rescan 재구성에 `report_*` 필드(`report_indexed`/`report_notes_count`/`report_collected`/...) 추가.
    - `_doc_indexed` report, get_library enrich에 `report_filename_original`.
    - `notes_rag_query` 외 5개 엔드포인트 doc_type Literal에 report 추가, **report 검색 시 fs_div="all" 강제**(연결·별도 중립).
    - `safe_original_filename` 충돌 회피를 `_STANDARD_PDF_NAMES` 기준으로 일반화.
  - **프런트** `src/static/index.html`:
    - JS 상수 `DOC_ICON/DOC_FULL/DOC_SHORT/DOC_FSDIV`(report=📄/사업보고서/사업/all), `docIndexed`/`docCount` report 분기.
    - 매트릭스 셀에 📄사업보고서 pill(3번째) 추가, absent 클릭은 **업로드 서브탭 프리셋**(DART수집 아님)으로 분기(`onAbsentDocClick`).
    - 업로드 드롭다운·프리셋 체크박스·Insights 문서선택자에 사업보고서 옵션, `detectDocTypeJs` 미러 추가.
  - **테스트** `tests/test_doc_type_report.py`(신규 7건), `tests/test_pdf_detect.py`(report 제거→재도입 전제로 1건 갱신).
