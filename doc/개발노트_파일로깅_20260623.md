# 개발노트 — 파일 로깅 추가 (setup 서버 사후 진단)

## 2026-06-23 10:25 작업 내역
- 작업 내용:
  - setup(frozen exe) 서버는 파일 로그가 없고 콘솔(stdout/stderr)로만 출력 → 더블클릭(콘솔 숨김) 실행 시 로그 유실, 사후 진단 불가 문제.
  - **Tee 방식 파일 로깅 추가**: 이 프로젝트는 `print(..., file=sys.stderr)` 를 광범위하게 써서 logging 모듈 설정만으로는 다 못 잡음 → stdout/stderr 스트림 자체를 Tee(콘솔+로그파일 동시 기록)해 uvicorn 로그·print·트레이스백을 전부 캡처.
  - 위치: `%LOCALAPPDATA%\prism-fs\logs\prism-fs_YYYYMMDD.log` (LOCALAPPDATA 부재 시 `~/.prism-fs/logs`). 보관 30일 초과 자동 삭제(기동 시 1회 정리). CLAUDE.md 로그 정책 준수.
  - `run_server.py`(setup 진입점)에서 **app import 전** 설치 → 기동/임포트 시점 로그까지 기록. 실패해도 기동 무중단(콘솔 전용 폴백).
