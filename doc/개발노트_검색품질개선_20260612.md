### Phase 1 — 검색 단 튜닝 (src\app.py)
- top-k 5→10(`SEARCH_TOP_K`), `MIN_MATCH_SCORE` 0.45→0.35, `POLICY_MIN_MATCH` 0.40→0.30,
  `LEXICAL_FLOOR` 0.30→0.28.
- `_note_unit_cos`: max-only → **max 0.8 + 상위3 평균 0.2** (`UNIT_MAX_W`).
- BM25 제목/청크 코퍼스 분리(`BM25_TITLE_W`=0.2) — 제목 토큰 희석 해소.
- **파라미터는 골든셋 스윕으로 확정**(u/b 6조합): 0.5 가중은 본문 MRR -0.11 회귀 →
  u0.8/b0.2 가 제목 +0.04·본문 무손실 균형점.
- **버그 수정**: BM25 전 문서 음수/0 점수 시 `max(…,1e-9)` 나눗셈이 음수를 수백만 배
  증폭(기존 합본 코퍼스에도 잠재) → 클립 후 max>0 일 때만 정규화.

### Phase 2 — 인덱스 재설계 (스키마 v3) + 전체 재인덱싱
- `CHUNK_CHARS` 450→250(+오버랩 50): **모델 max_seq_length 128토큰 정합** — 청크 뒷부분
  ~절반 무음 절단 해소. 페이지 스캔 캡(20p) 제거, `MAX_CHUNKS_PER_NOTE` 40→120.
- 저장 벡터 `round(5)`(JSON ~45%↓), 노트 `full_text` 전문 보존(RAG/스니펫용).
- **배치 임베딩**(`make_embeddings`, batch_size=32) — 재인덱싱 40문서 **3.6분**
  (기존 단건 호출 대비 수십 배). `src\reindex_all.py` 일괄 스크립트(--no-llm/--only).
- 전체 재인덱싱 40/40 성공. 인덱스 총 433MB(반올림·청크 증가 상쇄로 기존 376MB 대비 +15%).

### Phase 3 — 커버리지 확장
- **비주석 본문 섹션 인덱스**(`src\sections.py` + `index_sections.json`): 로마숫자
  목차(I.~XII.) 헤더 휴리스틱. 핵심 설계 — **주석 커버 페이지 제외**(중복 0) +
  마지막 주석의 "문서 끝까지" 아티팩트는 노트당 30p 캡으로 방어. 목차 점선 리더
  필터·앞부분 한정 TOC 판정·갭 허용 런으로 오판 차단(신한 Q3 실측 12섹션).
- RAG(`/api/notes/rag`)에 `include_sections`(기본 on) — 검증: "임원 및 직원 현황" →
  📑 본문 VIII p467 score 0.96 1위(기존 검색 불가 영역).
- **XBRL 크로스링크**(`xbrl_links.json`): fs_structured 계정명↔주석 제목 임베딩 매칭
  (하한 0.55, 상위 3). compare 후보에 `fs_links` 부착 → UI 💰 칩(계정명+금액).
  검증: 보험금융손익 주석 ↔ CIS 보험금융수익 sim 1.0.
  버그 수정: 타깃 fs_div="all"(사업보고서 pill) 시 키 미매칭 → 후보 자체 fs_div 사용.
- report 인덱싱 후 자동 생성 + `reindex_all.py --extras-only` 백필(20셀 완료).

### Phase 4 — LLM 리랭킹 (옵트인)
- `llm_rerank_candidates`: Ollama 로 후보 '순서만' 재조정(note_no 배열 강제 —
  할루시네이션 항목 추가 불가), 타임아웃 6s 실패 무시. compare `rerank` 플래그 +
  UI "🤖 AI 재정렬" 체크박스(reranked 플래그로 AI 개입 투명화).
- **A/B 실측(중요)**: "퇴직급여 부채 평가" — 기본 순서 [16 확정급여(정답), 17, 26]를
  qwen2.5:7b 리랭킹이 [17, 1, 16]으로 **악화**. 기본 검색이 이미 강함 → **기본 OFF
  유지가 데이터로 정당화됨**. 더 큰 모델 가용 시 재평가 권장.

### Phase 5b — 인덱스 이식 (GPU 없는 PC 재활용)
- `GET /api/library/export[?cells=…&include_raw=false]`: 셀 zip + manifest(스키마·
  임베딩 차원·백엔드). 기본 xbrl/·source/ 제외(용량 ~63%↓ — 신한 Q3 1셀 14.5MB).
- `POST /api/library/import`: manifest **차원 선제 검증**(512↔768 반입 차단),
  zip 경로 탈출 차단(..·절대경로·미등록 회사/기간), 셀 단위 병합(+overwrite 선택),
  카탈로그 자동 등록.
- `POST /api/library/rescan`: 디스크 스캔 카탈로그 재구성(`_cell_entry_from_disk` 공용)
  — 폴더 수동 복사 복구용. 검증: 20셀 재구성.
- UI: 매트릭스 상단 "📤 내보내기 / 📥 가져오기" 버튼.
