### 2. 자연어 질의 = 라이브러리에서 선택한 문서만 검색
- 문제: 기존엔 선택 회사들의 **전체 기간·문서유형**을 검색(doc_type 드롭다운 기준). 선택한 정확한 문서가 아니었음.
- **서버 `src/app.py` `notes_rag_query`**: `cell_keys`("회사~기간~문서유형" 목록) 파라미터 추가. 주어지면 그 조합만 로드(연결/별도 혼재 가능, `fs_div="all"`로 필터 해제). 출처별 `doc_type`을 응답에 포함(`cell_dt` 매핑 — 텍스트 폴백·PDF 링크 정확화).
- **클라이언트 `doRag`**: 선택 필수(미선택 시 안내 토스트). `SELECTED`→`cell_keys` 생성해 전달. 불필요해진 **문서유형 드롭다운(`rag-doctype`)·fs_div 제거**. 출처 칩은 `s.doc_type`로 회사·기간·연결/별도 표기 + 정확한 원본 PDF 링크/미리보기.
- 인트로: "📚 라이브러리에서 선택한 문서만 검색합니다" 명시.

### 3. 비교조회 보고서 순서 드래그&드롭 정렬 (`index.html`)
- 비교 대상 칩(`compare-targets-bar`)을 `draggable`로 — `⋮⋮` 핸들·"드래그해 순서 변경" 안내. `attachTargetDnD()`/`reorderTargets(drag,target)`가 `SELECTED` 순서를 재배열(아래로=대상 뒤, 위로=대상 앞). 결과가 떠 있으면 새 순서로 패널 재배치(재검색). CSS `.chip-drag`(grab)·`.dragging`·`.drop-target`.
