# 개발노트 — 가이드 닫기 버그 수정 + 전 탭 닫기 가능 안내

## 2026-06-17 작업 내역 (v0.11.0 → 0.11.1)

### 1. 퀵스타트 닫기 버튼 미동작 수정
- 원인: `.quickstart { display:flex }`가 `.hidden { display:none }`보다 **소스 순서상 뒤**라, "hidden" 클래스를 추가해도 `display:flex`가 이겨 숨겨지지 않음(특이도 동일 → 후순위 승).
- 수정: `.quickstart.hidden, .tab-guide.hidden { display:none !important; }` 추가(특이도/우선순위 확실히 우위). 닫기 정상 동작.

### 2. 전 탭에 닫기 가능한 가이드 추가
- 공용 메커니즘: `id="guide-<key>"` + `.tab-guide` + `.guide-x`(우상단 ✕). `dismissGuide(key)`가 숨기고 localStorage(`guideDismissed_<key>`)에 저장, `initGuides()`가 새로고침 시 닫힌 가이드 유지.
- 적용 탭:
  - 📚 라이브러리: 기존 퀵스타트(닫기 수정).
  - 🔍 비교조회: 기존 안내에 ✕ 추가(`guide-compare`).
  - 🤖 자연어 질의: 인트로 `<p>`를 닫기 가능 가이드로(`guide-rag`).
  - 📈 재무제표 비교: 인트로에 ✕(`guide-fs`).
  - 🧭 커버리지·공시갭: A~D 요약 가이드 배너 신규 + ✕(`guide-coverage`).
- CSS: `.tab-guide{position:relative;padding-right:30px}`, `.guide-x`(우상단, hover 진하게).
