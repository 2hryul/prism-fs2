# 개발노트 — 업로드 기간검증·PDF 더블클릭 복구·매트릭스 버튼 정리

## 2026-06-17 작업 내역 (v0.10.0 → 0.10.1)

사용자 지적 4건 수정.

### 1. 업로드 기간 불일치 검증 강화 (`src/app.py`)
- 문제: 연간 감사보고서(예: `감사보고서(2026.03.18)`)를 업로드하며 기간을 Q3로 잘못 선택해도 경고 없이 등록됨. 기존 `detect_period_from_text`가 "분기/반기" 키워드+파일명 접수일만 봐서 연간 보고서의 기간을 못 잡음 → 미스매치 경고(기존 `detectDiffs`+confirm)가 발동 안 함.
- 수정: `detect_period_from_text`에 **결산기준일(`YYYY년 M월 DD일`) 검출** 추가(`_STMT_DATE_RE`) — 3월=Q1·6월=Q2·9월=Q3·**12월=FY(연간)**. 명시적 "1분기/2분기/3분기/반기" 표기도 인식. `/api/library/detect`가 표지 다음 페이지의 결산일까지 보도록 **앞 5페이지** 스캔.
- 효과: 연결감사보고서(연간) → `2025FY` 검출 → 사용자가 Q3 선택 시 "기간 2026Q3→2025FY" 경고 후 [자동 채움]/확인. 분기 검토보고서 → `2026Q1` 정상.

### 2. PDF 더블클릭 전체 열기 복구 (`src/static/index.html`)
- 문제: 본문 하이라이트용 **텍스트 레이어(z-index 2)** 가 캔버스를 덮으면서 캔버스에 달린 `dblclick`을 가로채 새 창 열기가 동작 안 함.
- 수정: `renderPdfRange`에서 `dblclick`(+cursor/title)을 **`canvas` → `pageWrap`(부모)** 로 이동. 캔버스/텍스트레이어 어느 쪽을 더블클릭해도 버블링으로 핸들러 발동 → `#page=N` 앵커로 원본 PDF 새 창.

### 3. 라이브러리 "＋4사" 버튼 삭제 (`index.html`)
- 매트릭스 기간 헤더의 일괄 추가 버튼·`addPeriodAll` 함수 제거. 추가는 "분기/연간 자료 추가" 모달로 일원화.

### 4. 기간 전체삭제 = 헤더 텍스트 클릭 (`index.html`)
- "🗑 전체" 버튼 제거. 기간 헤더 텍스트(`2026Q1` 등)를 `.th-plabel-del`로 — **마우스 오버 시 빨간 강조+🗑·툴팁**으로 안내, 클릭 시 `deletePeriodAll`(확인 후 진행). CSS `.th-bbtn*` 제거.
