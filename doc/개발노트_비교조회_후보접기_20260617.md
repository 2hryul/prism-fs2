# 개발노트 — 비교조회 후보 목록 접기 버튼

## 2026-06-17 작업 내역 (v0.10.2 → 0.10.3)

### 작업 내용
주석 비교조회 결과에서 **선택된 후보만 남기고 나머지 후보를 접는 버튼**을 패널별로 추가. 후보가 많을 때(최대 10개) 화면 정리·집중도 향상.

### 변경 파일 (`src/static/index.html`만)
- **CSS**: `.cand-toggle`(파란 알약 버튼)·`.cand-list.collapsed .cand-row:not(.sel){display:none}` — 접힘 상태에선 선택(`.sel`) 행만 노출.
- **패널 헤더**: 후보 2개 이상일 때 `<button class="cand-toggle" id="candtog-{i}" onclick="toggleCandList({i})">나머지 N개 접기</button>` 추가(top 우측).
- **`toggleCandList(i)`**(신규): `cands-{i}`에 `collapsed` 토글, 버튼 라벨 "나머지 N개 접기↔펼치기" 갱신.

### 동작
- 기본: 펼침(전체 후보 노출).
- "나머지 N개 접기" 클릭 → 선택 항목 1개만 표시(+PDF 미리보기 유지). 다시 누르면 펼침.
- 패널별 독립 토글(신한 접고 KB 펼치기 가능).

### 검증 (브라우저)
- "공정가치" 검색(신한·KB 2026Q1) → 후보 10개. 접기 → 보이는 행 1개(선택), 버튼 "나머지 9개 펼치기". 펼치기 → 10개 복귀.
- 패널별 독립 동작·콘솔 error 0. 스크린샷 확인.

### 비고
- 접힘 상태에선 비선택 후보가 숨겨져 클릭 불가 → 다른 후보 선택하려면 펼치기. 의도된 동작.
- 헤더 `v0.1.0` 하드코딩 잔존(기존 이슈).
