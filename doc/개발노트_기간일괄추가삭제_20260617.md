# 개발노트 — 기간(컬럼)별 4사 일괄 추가/삭제 버튼

## 2026-06-17 작업 내역

### 작업 내용
라이브러리 매트릭스(회사 × 기간)의 **기간 헤더마다 4사 일괄 추가(＋4사)·삭제(🗑 전체) 버튼**을 추가. 연도/기간 단위로 4대 금융지주를 한 번에 수집·제거(v0.7.0 → 0.8.0).

### 변경 파일 (`src/static/index.html`만)
- **매트릭스 헤더**(`renderMatrix`): 각 기간 `<th>`에 라벨 + `.th-bbtn.add`(＋4사)·`.th-bbtn.del`(🗑 전체) 버튼.
- **`addPeriodAll(period)`**(신규): 해당 기간 4사를 순차 DART 수집(rate-limit 회피). 기존 `startCollect`(→`/api/library/collect`) 재사용 — FY는 백엔드가 FS-only 처리, 이미 수집된 PDF는 미덮어쓰기. 진행/결과는 매트릭스 상단 `#matrix-bulk-status`에 표시.
- **`deletePeriodAll(period)`**(신규): 해당 기간에 등록된 회사 셀만 `DELETE /api/library/{co}/{period}`로 일괄 제거. 단일 confirm, SELECTED 동기화, `EXTRA_PERIODS`에서 제거(빈 컬럼 잔류 방지).
- **상태 영역**: 매트릭스 위 `#matrix-bulk-status` div 추가.
- **CSS**: `.th-period`·`.th-bulk`·`.th-bbtn`(add=green/del=red pill).

### 결정 사항
- **백엔드 무변경**: 기존 단건 수집/삭제 엔드포인트를 루프 호출로 재사용(서버 변경 0). 순차 호출로 DART rate-limit 회피.
- **추가는 4사 전부 시도**: 이미 수집된 문서는 백엔드가 건너뜀(idempotent). 삭제는 실제 등록된 회사만 대상.
- 추가/삭제 모두 confirm 1회로 일괄 처리.
