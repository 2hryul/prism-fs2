라이브러리 매트릭스

회사·기간 칸을 클릭하면 비교 대상에 추가됩니다(여러 개 선택 가능). 빈 칸을 클릭하면 자료 업로드 화면으로 이동합니다. 각 칸의 숫자는 그 문서에서 인덱싱된 주석(footnote) 개수이며, 기간 머리글을 클릭하면 그 기간 4사 자료를 한 번에 삭제합니다.

프리셋 적용 문서:
선택된 항목이 없습니다.
🔍 키워드·주석번호로 4사의 같은 주석을 찾아 원문 PDF를 나란히 비교합니다. 예: 공정가치, 대손충당금, 32(주석번호).
먼저 📚 라이브러리에서 비교할 회사·기간을 선택하세요. · 문장으로 질문하고 AI 요약 답을 원하면 🤖 주석 자연어 질의 탭을 쓰세요. ✕
먼저 라이브러리 탭에서 비교 대상을 선택하세요.
ℹ️ 표·숫자는 원본 PDF 그래픽을 그대로 렌더링하며 AI는 숫자를 재구성·환산하지 않습니다. 주석 본문 자연어 질의는 주석 자연어 질의 (AI 보조) 탭을 이용하세요.

🤖 주석 자연어 질의 AI 보조 · 인용 강제

문장으로 질문하면 AI가 근거를 찾아 답합니다(예: "공정가치 Level 3 가정은?"). 답변은 항상 출처(회사·주석번호·페이지)를 동반하고, 숫자는 생성하지 않습니다(정량 비교는 📈 재무제표 비교 탭). 📚 라이브러리에서 선택한 문서만 검색합니다(회사·기간·연결/별도). 로컬 Ollama 미가동 시 검색 결과(출처)만 표시.
키워드로 4사 주석을 표로 나란히 보려면 🔍 주석 비교조회 탭을 쓰세요. ✕

ℹ️ AI 답변(보라 박스)은 주석 텍스트 기반이며 출처 인용을 동반합니다. 숫자 재구성·단위 환산은 하지 않습니다(human-in-the-loop 검증 필요).

📈 재무제표 비교 결정론

연결(CFS)/별도(OFS) 재무제표를 원문 그대로 비교합니다. 증감·차이·비율 등 파생값은 결정론 계산이며 각 값에 ⓘ 계산식 근거가 붙습니다. (단위 환산·AI 재구성 없음)
기간: FY=연간확정(사업보고서 기준 재무데이터) · Q1~Q3=분기 잠정(검토). FY 손익·현금흐름은 전기 연간과 비교합니다.✕

🔒 원문 보존(thstrm/frmtrm/frmtrm_q) · 단위 환산 0 · 파생값은 결정론 계산 + 계산식 provenance · 출처 DART fnlttSinglAcntAll → fs_structured.json.

🧭 커버리지·공시갭 신한 중심

4사 기준. 주석 "구조"만 비교하며 숫자·단위는 재구성/환산하지 않습니다.

🧭 4사 주석을 주제별로 한눈에 — A 어떤 회사가 어떤 주제 주석을 공시했는지(전용/통합/미발견), B 신한에만/동종에만 있는 주석, C 표준 주제로 4사 정렬, D AI 비교 초안(옵트인). 숫자·단위는 재구성하지 않습니다. ✕

A. 횡단 커버리지 매트릭스

주제 × 회사 → 전용 주석 / 통합·관련 / 미발견. 전용·관련 셀을 더블클릭하면 비교 탭에서 4사 전체를 해당 주제로 검색합니다.

전용 주석 통합·관련 미발견

B. 신한 vs 동종 주석 차집합

base=신한, peers=KB·하나·우리. 의미(임베딩) 매칭 임계값 0.62 기준. 제목이 달라도 의미가 같으면 대응으로 간주합니다.

C. 주제별 4사 정렬 (표준 주제 매핑)

회사마다 번호·제목이 다른 주석을 canonical 주제로 분류해 4사를 나란히 정렬(임베딩, AI 무경유). 칩 클릭 시 원본 PDF.

"주제 매핑 실행"을 눌러 4사를 표준 주제로 정렬하세요.

D. AI 비교 메모 초안 옵트인·인용 강제

선택 주제에 대해 4사 주석의 회계정책·가정 차이를 AI가 초안으로 정리(로컬 Ollama 옵트인). 숫자 생성 없음, 문장별 출처 동반, 검토 필요.

ℹ️ 커버리지·차집합·주제 매핑 분류는 임베딩 코사인 + 규칙으로만 산출되며 AI가 주석/숫자를 생성하지 않습니다. AI 비교 초안(D)은 주석 텍스트 기반·출처 인용 동반이며 담당자 검토가 필요합니다. (연결/별도 동일 축끼리 비교)

분기/연간 자료 추가✕

DART OpenAPI에서 연결·별도 검토보고서 PDF·재무제표를 자동 수집해 인덱싱합니다. (.env DART_API_KEY 필요)

수집 후 선택한 문서만 자동 인덱싱. 매트릭스 빈 셀을 클릭하면 해당 셀을 바로 수집합니다.

📄 사업보고서 본문은 DART에서 첨부 PDF로 제공하지 않는 경우가 많습니다(본문=HTML 공시). 첨부에 있으면 자동 수집하고, 없으면 PDF 업로드 탭에서 직접 올려 주세요.

DART에서 받은 PDF를 회사·기간·문서유형을 지정해 1개씩 업로드합니다. 업로드 후 자동 인덱싱. 파일 선택 시 회사/기간/문서유형을 자동 감지해 보정 제안합니다.
